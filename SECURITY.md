# Security Policy

`@opoha/core` follows the org security policy.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities in this repository.

Prefer one of:

1. **GitHub private vulnerability reporting** on this repository (Security → Report a vulnerability), when enabled.
2. Email **security@opoha.dev** with package version, impact, and steps to reproduce.

Full policy: [Opoha SECURITY.md](https://github.com/Opoha/.github/blob/main/SECURITY.md).

## Non-security bugs

See [CONTRIBUTING](./CONTRIBUTING.md) and the org [CONTRIBUTING](https://github.com/Opoha/.github/blob/main/CONTRIBUTING.md).
